# ADR-0007: CSP with hashes, nonces only where needed

Link pages (`/b/`, `/h/`) must stay static and cacheable, so per-request nonces are avoided. The
no-flash theme script is a fixed string; its SHA-256 goes into `script-src`, and a unit test
recomputes it so the header and script cannot drift. Next.js App Router also emits inline flight
scripts; for statically rendered routes their hashes are collected at build time and written into
the headers config; dynamic signed-in routes use a nonce from middleware. Enforced and tested in
Milestone 10 (SEC-03).
