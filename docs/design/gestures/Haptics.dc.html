WHAT THE WEB CAN DOAndroid Chrome supports the Vibration API (durations only, no strength). Safari on iPhone has no Vibration API; the only route is toggling a hidden switch control, which gives one light tick per call. A pattern is a few ticks in a row.
RULESAt least 60 ms between haptics. Only fire during the user's own gesture, never for other people's live changes. Nothing on scroll or on cancel. Haptics are never the only signal: every one has a visual twin.
SETTINGSettings › Kitchen › Haptics, on by default. If the device can't do it, the switch is hidden. Treat the iPhone path as best effort: if Safari changes, the app still works the same, just without the tap.
