# KitchenTab — Claude Code handoff kit

Everything Claude Code needs to build, test and verify KitchenTab from an empty repo.

## Start in 4 steps
1. Create an empty folder (or GitHub repo) and copy everything in this kit into its root.
2. `git init && git add -A && git commit -m "docs: KitchenTab spec and handoff kit"`
3. Open Claude Code in that folder.
4. Paste prompt 1 from `KICKOFF_PROMPT.md`. Review its reply, say go, and use prompt 2 for each of the 10 milestones. After the last one, paste prompt 4 (final verification).

## What's inside
| Path | What it is |
| --- | --- |
| `CLAUDE.md` | Standing rules Claude Code reads every session (money, sync, notifications, tests) |
| `KICKOFF_PROMPT.md` | Kickoff, per-milestone, follow-up and final verification prompts |
| `docs/PRD.md` | Full PRD and technical spec: 22 sections incl. fridge and pantry (§19), install + push (§20), multi-user sync (§21), testing (§22) |
| `docs/TEST_PLAN.md` | ~250 tests with IDs, harnesses, real-device QA, release gate, report template |
| `docs/design/` | 16 approved screen mockups + how to read them |
| `docs/reference/compute_shares_reference.py` | Executable spec for split math |
| `packages/fixtures/money_cases.json` | Golden money test cases (9) generated by the reference |
| `.env.example` | Every environment variable the app needs |

## Accounts you'll need, by milestone
- **3:** Google Cloud OAuth client; Twilio Verify (or another SMS provider); a transactional email provider and a sending domain with SPF/DKIM/DMARC.
- **5:** an API key for a vision-capable LLM.
- **9:** VAPID keys for Web Push (generate with `npx web-push generate-vapid-keys`; no account needed). A real iPhone and Android phone for device QA.
- **10:** hosting (Vercel + Fly.io or AWS), Sentry, analytics.

Local development and every automated test need none of these: fakes are used by default.
